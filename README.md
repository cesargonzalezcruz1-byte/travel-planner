# Travel Planner

Family trip itinerary web app (installable on phones). Data, sign-in and documents live in Firebase
(project `travel-planner-db061`) behind security rules; this repository only holds the app code - no trip data.

- Family: open the site and enter the family password.
- Editors (Cesar, Debora): "Sign in with Google".
- `rules/` holds the Firestore and Storage security rules (pasted into the Firebase console).
